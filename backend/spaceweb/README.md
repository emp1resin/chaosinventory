# Бесплатный backend на SpaceWeb

Сайт остаётся на GitHub Pages. Эта папка заменяет только API-сервер на
`chaosinventory-data.*.chatgpt.site`. Данные персонажей запрашиваются у
`https://chaosage.ru`; старый сторонний `chaosage.space` не используется.

## Перед переключением

1. Зарегистрируйте бессрочный тариф «Бесплатный» SpaceWeb. Понадобится
   подтверждение телефона. Получите технический адрес `логин.temp.swtest.ru`
   и включите бесплатный сертификат для него. Разрешение на исходящие HTTPS
   запросы к игре нужно проверить на самом хостинге: документация тарифа не
   подтверждает эту конкретную возможность.
2. Разместите `.htaccess` и `index.php` в корне сайта через файловый менеджер
   или FTP. В PHP должны быть включены `curl` и `PDO MySQL`.
3. Проверьте `https://логин.temp.swtest.ru/health` и
   `https://логин.temp.swtest.ru/api/profile-html?name=Thrandu1l`. Второй
   ответ должен быть HTML профиля с кодом 200. Если ответ 502/504, посмотрите
   журнал PHP: это означает, что сервер не смог получить данные игры.
4. Отдельно проверьте `GET /api/game-json?request=clans` и CORS с заголовком
   `Origin: https://emp1resin.github.io`.
5. Для отчётов об ошибках создайте MySQL таблицу из `reports.sql` и задайте
   серверные переменные `CHAOS_REPORT_DSN` (`mysql:host=...;dbname=...;charset=utf8mb4`),
   `CHAOS_REPORT_USER`, `CHAOS_REPORT_PASSWORD`. Если на тарифе нельзя задавать
   переменные окружения, конфигурацию придётся хранить вне document root;
   не размещайте пароль в публичном репозитории. Импорт персонажей работает и
   без БД, но отправка баг-репорта ответит 503 до подключения хранилища.
6. Проверьте API и весь импорт на Wi-Fi и LTE в РФ без VPN. Только после этого
   задайте GitHub Actions variable `CHAOS_API_BASE` равной новому HTTPS адресу
   и запустите workflow `Build GitHub Pages`. Переменная передаётся Vite при
   сборке; пустое значение оставляет текущий backend.

План отката: очистить `CHAOS_API_BASE`, запустить `Build GitHub Pages` снова.
Сборка переключает источник API, но не затрагивает локальные сохранения игроков.

Ограничение бесплатного тарифа: 15 CP, блокировки после превышений; публичная
нагрузка и исходящий HTTPS должны быть измерены до переключения основного сайта.
