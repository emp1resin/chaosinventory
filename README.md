# ChaosInventory

Примерочная персонажей «Аватары: Эпоха Хаоса».

- Публичный сайт: https://emp1resin.github.io/chaosinventory/
- Исходный код: [`site-source/`](site-source/)
- Описание проекта и локальный запуск: [`site-source/README.md`](site-source/README.md)

В корне репозитория находятся готовые файлы для GitHub Pages. При изменении
`site-source/` GitHub Actions собирает проект и обновляет эти файлы. Для работы
автоматического обновления в настройках репозитория GitHub Actions должен иметь
право записи в репозиторий; GitHub Pages должен публиковать ветку `main`, папку `/`.
