# ChaosInventory

Примерочная и калькулятор билдов для «Аватары: Эпоха Хаоса». Загружает открытые данные персонажа по нику, позволяет менять экипировку, модификации, руны, навыки и сравнивать итоговые параметры.

В репозитории находится полноценный автономно собираемый проект. Сервер, база данных, секреты и аккаунты не требуются.

## Возможности

- импорт персонажа, экипировки, модификаций, обычных рун, рунных слов и рун Разлома;
- 1 054 предмета из всех разделов официального FAQ;
- ручная настройка характеристик, навыков, мастерства и клановых артефактов;
- быстрый выбор комплектов;
- расчёт основных, магических и вторичных параметров;
- локальные сохранения и сравнение билдов;
- расчёт подтверждённой магазинной стоимости в серебре, золоте и очках контроля;
- полные описания рун Разлома.

## Требования

- Node.js 22 LTS или новее;
- npm 10 или новее;
- доступ к доменам `chaosage.ru`, `chaosage.space` и `chaosage.app`.

## Локальный запуск

```bash
npm ci --legacy-peer-deps
npm run dev -- --host 0.0.0.0 --port 43127
```

Откройте `http://localhost:43127`.

## Production-сборка

```bash
npm run build
npm run preview -- --host 0.0.0.0 --port 43127
```

Готовая статика создаётся в каталоге `dist/`.

## Обновление каталога предметов

```bash
npm run update:data
```

Команда получает актуальные предметы из официального FAQ и игрового API, затем пересоздаёт `src/components/ItemsAll.jsx`.
