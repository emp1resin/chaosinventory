# Источники данных

## Домены

| Домен | Назначение |
|---|---|
| `https://chaosage.ru` | официальный FAQ, изображения и игровой API `sAPI2.php` |
| `https://chaosage.space` | парсер профиля, данные религий и кланов |
| `https://chaosage.app` | список ников для автодополнения |

Секреты и токены не используются.

## Runtime API

### Базовый профиль

```text
GET https://chaosage.space/getAvatarsDataByName?name=<НИК>
```

Используется в `InputNameForFinding.jsx`. Возвращает:

- расу или высшую форму;
- профессию и уровень профессии;
- религию;
- клан;
- уровень;
- базовые характеристики;
- названия надетых предметов.

### Список экипировки

```text
GET https://chaosage.ru/sAPI2.php?user_name=<НИК>&request=user_equipment_list
```

Возвращает ID экземпляров вещей по слотам: `arms`, `gloves`, `weapon`, `belt`, `boots`, `helm`, `amulet`, `shield`, `ring1`, `ring2`, `armor`.

### Информация о вещи

```text
GET https://chaosage.ru/sAPI2.php?id=<ID>&request=equipment_info
```

Используется для:

- итоговых параметров модифицированной вещи;
- обычных рун и рунного слова;
- типа комплекта;
- `original_id`;
- числового ID руны Разлома в поле `breachRune`;
- дополнительных параметров вроде вампиризма, уклонения и ярости.

Если `breachRune != 0`, приложение делает ещё один запрос `equipment_info` с этим ID. Например:

- `1172` → FEHU;
- `1178` → KAUNAZ;
- `1179` → LAGUZ;
- `1183` → MANNAZ.

Такой подход поддерживает будущие ID без жёстко прошитой таблицы.

### Фракция

```text
GET https://chaosage.ru/sAPI2.php?user_name=<НИК>&request=user_fraction
```

Используется поле `fractionRLevel`.

### Позиция в клане

```text
GET https://chaosage.ru/sAPI2.php?user_name=<НИК>&request=clan_list_by_user_name
```

Позиция определяется индексом персонажа в полученном списке.

### Религии и клановая слава

```text
GET https://chaosage.space/religionAndClansData
```

Используются:

- `religionArr` — список религий;
- `clansArr` — текущая слава кланов;
- `rowA[].religionInformation` — бонусы священных артефактов, если поле присутствует.

Источник нестабилен: `rowA` может быть пустым. Код обрабатывает это как отсутствие бонусов. Иллириана принудительно исключена из бонусов, включая старые сохранения.

### Автодополнение ников

```text
GET https://chaosage.app/resources/nickParse.php
```

Не является обязательным для ручного ввода ника.

## Изображения

Иконки загружаются напрямую:

```text
https://chaosage.ru/images/<ПУТЬ>
```

Локальных копий игровых изображений в репозитории нет. Для полностью автономного зеркала изображения потребуется скачать и заменить URL.

## Генератор каталога

`scripts/update-catalog.mjs`:

1. загружает категории вещей `type=1..19` и `type=21`;
2. извлекает item ID и названия комплектов;
3. запрашивает `equipment_info` для каждого базового предмета;
4. преобразует API-поля в внутреннюю структуру;
5. записывает `src/components/ItemsAll.jsx`.

Генератор требует сеть и может выполняться около минуты.

## CORS и доступность

API не имеют официального договора стабильности. Возможны:

- изменение JSON-полей;
- ограничение CORS для нового домена;
- временная недоступность;
- пустые ответы;
- блокировка частых запросов.

Для надёжного production-развёртывания создайте serverless-прокси с кэшированием и ограничением частоты. Не скрывайте ошибки API: интерфейс должен оставлять ручной ввод как резервный путь.
