# Проверка расчётов 27 сентября 2026 года

Проверка использует тот же редьюсер импорта и тот же компонент расчёта, что и сайт. Входные данные получены из открытых API игры. Навыки, мастерство, клановые артефакты и благословения выставлены по данным пользователя. Снимки параметров персонажей относятся к 26 сентября; экипировка в игре может меняться.

## `destinys`

Текущие экземпляры надетых вещей совпали с присланными изображениями. Кольца оживления на изображении находятся в инвентаре и в расчёте не участвуют. На сапогах есть 1% вампиризма; на доспехе руна FEHU даёт 4%, итог — 5%.

При пяти мечах, трёх сферах, шести масках и одной Руне правителей из списка клана расчёт уступает игровому снимку на 23 брони, 23 сопротивления, 3 восстановления здоровья и 0,5 ОД на действие. Дополнительная руна закрывает все четыре разницы одновременно. В коде уже была настройка турнирной руны, но её управление было скрыто, а расчёт не применял её. Теперь она доступна отдельно. Игровой API не подтверждает владение турнирной руной, поэтому сайт не включает её автоматически.

При смене вещей результат выводится без сравнения со старым состоянием. Источник дополнительного 1% из игрового снимка пока не установлен. Он не следует из описания перечисленных навыков и не может быть общим для всех аватаров.

## `mellstroy`

Текущий игровой API сообщает посох «Око Аканы», три вещи Альматеи, пустые слоты наручей и перчаток. Это не тот снимок экипировки, при котором были записаны 356–496 урона и 339 атаки. Сайт для текущего состава с указанными навыками считает 123–130 урона и 57 атаки. Разница с устаревшей таблицей не доказывает ошибку формулы. Стабилизатор 9 уровня с мастерством «Эксперт» даёт 9% экономии по официальному описанию навыка; в присланном игровом снимке 10%. Источник ещё 1% по этому снимку не найден.

## `LICHonTHEbeach`

При первой проверке на персонаже был надет комплект Полнолуния с рунами LAGUZ, FEHU, MANNAZ и KAUNAZ. Сейчас игровой API возвращает булаву Солнца и смешанный набор вместо комплекта Полнолуния. Поэтому повторить исторические 10005–12082 урона на текущем импорте невозможно. Ранее на историческом наборе совпали броня 3016, защита 7027, ОД 446, сопротивление 1841, крит. удар 1201, устойчивость 561, парирование 92, реакция 221, пробой 1219, уклонение 21%, магическое уклонение 12%, вампиризм 12% и остальные защитные проценты после поправок комплектного бонуса, клановой славы и сложения уклонения.

Исторический расчёт без временных эффектов давал 9352–11396 урона и 15593 атаки. На снимке действовали эликсиры великого опустошения (+500 и +15% урона оружием) и наступления (+300 и +10% атаки); API их не возвращает, сайт пока не рассчитывает временные эффекты. Экономия зелий теперь 0%, как в игровом снимке.

## `Thrandu1l` и экономия зелий

На текущей экипировке и с навыками «Громила» 14, «Жизненная сила» 4 (в интерфейсе «Регенерация»), «Уворотливость» 6 расчёт совпал со всем присланным игровым снимком: урон 287–304, атака 950, защита 760, броня 88, ОД 162, ОД на действие 9 (9,3), сопротивление 69, парирование 48, реакция 20, восстановление здоровья/маны 132/14 и все указанные вторичные проценты, включая 0% экономии зелий. Эти значения закреплены в `scripts/verify-characters.mjs`.

Причина ложного 1%: `Results.jsx` раньше всегда добавлял единицу к бонусу навыка, даже если навыка, комплектного бонуса или руны не было. По официальному описанию «Алхимического стабилизатора» новичок не получает экономию, эксперт получает 1% за уровень, мастер 2% за уровень. Убрана безусловная единица; экран показывает итоговую экономию, включая руну Разлома, и 0% при отсутствии источников.

## Импорт нового персонажа

При загрузке другого ника сбрасываются навыки, мастерство, клановые артефакты, турнирная руна и благословения. Карты надетых вещей и их модификаций теперь создаются заново, чтобы новый импорт не менял объект предыдущего билда. `scripts/test-import-reset.mjs` проверяет сброс и отсутствие мутации предыдущего состояния. Отдельно сохранённые пользователем билды остаются в браузере намеренно.

## Повторить проверку

```bash
node scripts/test-import-reset.mjs
node scripts/verify-characters.mjs
npm run build
```

Для точной повторной сверки исторического `LICHonTHEbeach` нужен сохранённый билд с ID и модификациями тех экземпляров вещей или новый снимок параметров после загрузки его нынешнего набора, с указанием действующих эликсиров. Открытые API содержат только текущую экипировку.
