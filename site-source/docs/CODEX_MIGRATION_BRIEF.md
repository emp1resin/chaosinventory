# Задание Codex: перенос «Кузницы билдов»

Используй `sites:sites-building` для переноса существующего React/Vite проекта и `sites:sites-hosting` для публикации. Используй `skill-creator` для отдельного навыка сопровождения проекта, если он создаётся по этому заданию. Сохраняй исходную архитектуру и расчёт, не заменяй приложение макетом.

Исходный артефакт — переданный пользователем `chaos-build-forge-transfer.tar.gz`. В нём `README.md`, `package.json`, `package-lock.json`, `vite.config.ts`, `index.html`, `src/`, `scripts/`, `public/`, `docs/`. Прочитай `docs/ARCHITECTURE.md`, `docs/DATA_SOURCES.md`, `docs/MIGRATION.md`, `docs/TRANSFER_PROMPT.md`, `docs/PROJECT_INVENTORY.md`. Скриншоты Cursor в беседе показывали дерево файлов и способ выгрузки; источником кода является архив.

Цель: сохранить функциональность примерочной и калькулятора билдов «Аватары: Эпоха Хаоса» и опубликовать работающий сайт с публичным доступом по ссылке без обязательной регистрации. Сохранения остаются локальными в браузере, если пользователь не попросит их перенести. Серверная БД и секреты не требуются.

Порядок:

1. Установи зависимости `npm ci --legacy-peer-deps`, не удаляй lock-файл; собери `npm run build`.
2. Сохрани `Results.jsx` единым расчётным движком, а `ItemsAll.jsx` — снимком каталога. Не меняй формулы без сверки с официальным FAQ. Не добавляй неподтверждённые цены.
3. Проверь ручной выбор предметов, обычные руны, STORM, FEHU/LAGUZ, импорт ников `DestinyS` и `LICHonTHEbeach`, два сохранения и сравнение, отсутствие бонусов Иллирианы. При недоступности API оставь ручной ввод.
4. Проверь внешние запросы с production-домена: `chaosage.ru`, `chaosage.space`, `chaosage.app`. Если основной импорт блокируется CORS, добавь ограниченный прокси только для известных endpoint с таймаутом, кэшем и ограничением частоты. Не делай открытый URL-прокси.
5. Опубликуй сайт для всех, проверь статус deployment и фактический режим публичного доступа. Сообщи ссылку и конкретные ограничения, которые удалось подтвердить.

Документ фиксирует задание на момент переноса; фактические результаты тестов и публикации отмечай отдельно.
