# Готовый промпт для переноса

Скопируйте текст ниже и приложите архив проекта.

---

Мне нужно перенести и продолжить разработку существующего проекта «Кузница билдов» для браузерной игры «Аватары: Эпоха Хаоса».

Я прикладываю полный архив исходников. Не создавай проект заново и не заменяй расчётную логику упрощённой реализацией. Сначала распакуй архив, прочитай:

- `README.md`;
- `docs/ARCHITECTURE.md`;
- `docs/DATA_SOURCES.md`;
- `docs/MIGRATION.md`;
- `docs/PROJECT_INVENTORY.md`.

## Текущий стек

- React 17;
- Redux 4;
- Vite 8;
- Material UI 4;
- Bootstrap 5;
- JavaScript/JSX, конфигурация Vite на TypeScript;
- статическая production-сборка в `dist/`.

## Что уже реализовано

- загрузка персонажа по нику;
- импорт экипировки и модификаций;
- обычные руны и рунные слова;
- импорт рун Разлома по числовому ID API;
- ручное и массовое применение рун;
- комплектная экипировка;
- характеристики, навыки, расы, высшие формы, профессии, кланы и религии;
- единый движок расчёта в `Results.jsx`;
- локальные сохранения;
- сравнение билдов тем же расчётным движком;
- магазинная стоимость по подтверждённым валютам;
- локальный каталог из 1 054 предметов;
- Иллириана не имеет бонусов.

## Обязательные ограничения

1. Не создавай второй калькулятор. `Results.jsx` является источником истины и используется сравнением.
2. Не меняй игровые формулы без проверки официального FAQ.
3. Не считай рыночную цену, стоимость модификаций или рун Разлома без достоверного источника.
4. Сохрани ручной ввод как fallback при отказе API.
5. Не добавляй обязательную регистрацию или БД без отдельного согласования.
6. Не удаляй `package-lock.json`.
7. Устанавливай зависимости командой `npm ci --legacy-peer-deps`.
8. Проверяй импорт минимум на `DestinyS` и `LICHonTHEbeach`.

## Внешние источники

Проект обращается к:

- `https://chaosage.ru`;
- `https://chaosage.space`;
- `https://chaosage.app`.

API неофициальные и могут блокироваться CORS. Если новый production-домен не может обращаться к ним напрямую, создай безопасные serverless-прокси только для фиксированных endpoint и параметров. Не делай открытый URL-прокси.

## Первое задание

1. Разверни проект без функциональных изменений.
2. Выполни:

```bash
npm ci --legacy-peer-deps
npm run build
```

3. Запусти приложение.
4. Проверь импорт `DestinyS` и `LICHonTHEbeach`.
5. Проверь обычные руны, STORM и FEHU/LAGUZ.
6. Создай два сохранения и сравни их.
7. Проверь, что Иллириана не меняет параметры.
8. Проверь production CORS.
9. Сообщи только реальные ошибки и необходимые изменения.

После успешного переноса продолжай разработку существующей архитектуры, а не переписывай проект без необходимости.
